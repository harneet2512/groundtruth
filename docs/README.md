# Documentation map

The repository keeps the three entrypoint files at the root:

- [`README.md`](../README.md) — project overview and quick start.
- [`CHANGELOG.md`](../CHANGELOG.md) — release history.
- [`CLAUDE.md`](../CLAUDE.md) — agent operating instructions.

Supporting material is grouped by purpose:

| Folder | Contents |
| --- | --- |
| [`architecture/`](architecture/) | Contracts, pipeline boundaries, parity, and architecture remediation. |
| [`audits/`](audits/) | Conformance, bug-fix, runtime, localization, and wiring audits. |
| [`benchmarks/`](benchmarks/) | Benchmark runbooks, setup plans, live-run protocols, and validation sets. |
| [`metrics/`](metrics/) | Metric definitions, required run metrics, and deep-metric guidance. |
| [`operations/`](operations/) | Operational protocols that are followed during live runs. |
| [`plans/`](plans/) | Current specifications, goals, and next-session execution plans. |
| [`research/`](research/) | Experiment registry and research notes. |
| [`sessions/`](sessions/) | Dated handoffs, summaries, comparisons, and historical decisions. |
| [`archive/`](archive/) | Superseded or ambiguous historical notes retained for reference. |

Existing documentation folders remain in place. This reorganization moves root
notes only; it does not delete content.
